# S1 unimodal GRU — notes

**Plan's prediction:** minFDE₁ ≈ 3–4 m. **Actual:** minADE 3.22, **minFDE 8.50 m**,
MR 0.83 (CV: 4.41 / 11.69 / 0.85). Same story as S0: right ordering, wrong
absolute scale for a 6 s horizon.

Design choices:
- **Displacements in, displacements out.** Input is Δ-position per step (a
  velocity signal: small, stationary numbers). Output is 60 displacements,
  cumulatively summed — the frame origin is the last observed point, so the
  cumsum *is* the position. The net only has to learn "how velocity evolves".
- **One-shot decoding** (all 60 steps from one vector) instead of autoregressive.
  No exposure bias (it never consumes its own predictions), and it's one matmul.

Why it beats CV: it learns typical speed profiles (decelerating cars keep
decelerating; cars stopped at t=49 often start moving).

Why it can't go far: **a single output trained with a regression loss predicts
the conditional mean.** At an intersection the mean of "left" and "straight" is
a path through the corner of a building. MR barely moved (0.85 → 0.83): the
endpoint is still >2 m off in 83% of scenarios. More capacity wouldn't fix
this — the *output space* is wrong. That's what S2 changes.
