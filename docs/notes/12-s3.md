# S3 polyline transformer — notes

**Plan's prediction:** minFDE₆ ≈ 1.5–2 m. **Actual:** minADE₆ 1.18,
**minFDE₆ 2.45 m**, MR 0.41, brier-minFDE 3.09 (S2: 1.53 / 3.55 / 0.60 / 4.14).
0.92 M parameters, 40 epochs at ~20 s/epoch on an RTX 4060 (run alone).

## The idea
An agent's history is a polyline through time; a lane centerline is a polyline
through space. Treat them as *the same kind of thing*:

1. **Polyline → token.** A small PointNet-style encoder per polyline: per-point
   MLP, max-pool over the points, concatenate the pooled vector back onto every
   point, repeat, final max-pool. One 128-d token per agent / per lane.
2. **Tokens → context.** 4 layers of self-attention over all ~90 tokens. "Which
   lane am I in", "who is in front of me" and "where does that lane lead" are
   all the same operation: attention between tokens.
3. **Focal token → K-mode head**, reused verbatim from S2. The S2→S3 gain is
   therefore purely the encoder's: same head, same loss, same data.

## Details that matter
- **Max-pool is order-blind**, so the features must carry order and place.
  Agent points: (x, y, Δx, Δy, Δ-valid, t). Lane points: (x, y, Δx, Δy,
  is_intersection) — Δ gives the travel direction. The plan listed only
  (Δx, Δy, valid) for agents; that would have hidden *where* the other agents
  are, so position and time were added.
- **Separate encoders** for agents and lanes (different features), plus a learned
  type embedding (focal / other agent / lane) added to each token.
- **Padding is inert in two places:** invalid points are set to −∞ before the
  max-pool (all-invalid polylines pool to 0), and invalid tokens are excluded via
  `src_key_padding_mask`. Tests prove it: garbage in padded rows or at
  unobserved timesteps does not change the output.
- Pre-norm transformer (`norm_first=True`) + final LayerNorm, dropout 0.1.

## Why not 1.5–2 m?
Published models in that range train on all ~200k scenarios, usually with
augmentation, lane-graph connectivity and much more refined decoders. This is
15k scenarios (7.5%) and a plain MLP head. The train/val loss gap at the end
(2.03 vs 2.11) says the model is starting to be data-limited, not
capacity-limited. Task 15 (full data) is the lever, not more layers.

*Update:* confirmed — the same model on the full training set reaches 1.88 m.
