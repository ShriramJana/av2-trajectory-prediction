# S2 K=6 modes + winner-take-all — notes

**Actual:** minADE₆ 1.53, **minFDE₆ 3.55 m**, MR 0.60, brier-minFDE 4.14.
Same encoder as S1, same data, 40 s of training: minFDE 8.50 → 3.55.
The entire gain comes from changing the output space and the loss.

**Winner-take-all:** per scenario, find the mode closest to GT (by ADE), apply
the regression loss to *that mode only*, and train the logits with cross-entropy
to predict which mode won. If all K modes were regressed toward GT, all K would
converge to the same conditional mean (mode collapse = S1 six times). Under WTA
a mode only gets gradient from scenarios it already explains best, so modes
specialize — a learned clustering of futures.

Health check — share of val scenarios won by each mode:
22% / 26% / 7.5% / 8.5% / 15% / 20%. No dead modes. (The classic WTA failure:
one lucky mode wins everything early and the rest never get gradient.)

What the modes are: see `results/figures/s2/` — a fan of left / straight / right
at several speeds. Because along-track error dominates (see the S0 notes),
several modes differ mainly in *speed profile*, not direction.

Honest caveats:
- min-over-K metrics reward spraying: 6 guesses are judged only by the best
  one. MR 0.60 says that in 60% of scenarios even the best endpoint misses by
  >2 m. brier-minFDE (4.14 vs 3.55) adds a 0.59 penalty, i.e. the winning mode
  gets only modest probability on average.
- S2 has never seen a lane. Its turn modes are generic "a turn like this
  happens sometimes" shapes, not "this lane turns right here". Turning
  scenarios: minFDE 7.70 m vs 2.75 m for straight ones.
